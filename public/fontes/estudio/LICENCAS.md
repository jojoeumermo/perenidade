# Fontes do estúdio de design

Cópias estáticas (um arquivo por peso, só o alfabeto latino) das fontes livres do site, usadas pelo estúdio para
exportar SVG e PDF com o texto convertido em curvas. Todas são distribuídas sob a SIL Open Font License 1.1 (o texto
completo está em `OFL.txt`). Foram geradas a partir dos arquivos do repositório google/fonts com o fontTools
(instância por peso e recorte de caracteres), sem outra modificação no desenho.

| Arquivos | Família | Direitos |
| --- | --- | --- |
| `serifa-*.ttf` | EB Garamond | Copyright 2017 The EB Garamond Project Authors (https://github.com/octaviopardo/EBGaramond12) |
| `sans-*.ttf` | Inter | Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter) |
| `mono-*.ttf` | IBM Plex Mono | Copyright 2017 IBM Corp. |
| `manuscrita-*.ttf` | Caveat | Copyright 2014 The Caveat Project Authors (https://github.com/googlefonts/caveat) |

Os nomes reservados das fontes (Reserved Font Names, quando houver) não são usados nestes arquivos derivados: aqui
eles se chamam pelo papel no estúdio (serifa, sans, mono, manuscrita).
