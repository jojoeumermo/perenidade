# Perenidade

Biblioteca de Alexandria comunitária: conhecimento livre, gratuito e preservado.

- Next.js (App Router) + Tailwind CSS + Supabase (a integrar)
- Conteúdo em MDX versionado no Git; PDFs de terceiros **nunca** são hospedados (apenas metadados e links externos)
- Moderação por rascunhos (`pending` → `approved`), revertível via Git

```bash
npm install
npm run dev
```

Status: template visual (home). Próximos passos: modelagem Supabase + RLS, rotas MDX, login OAuth, moderation board.
