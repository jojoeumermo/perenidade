```suarealidade
Qual aparelho você mais usa (celular, computador, TV)? Já perdeu alguma coisa por não ter salvado ou por falta de espaço? O que você fez?
```

## Hardware e software

Todo computador tem duas partes que dependem uma da outra:

- **Hardware** é a parte física: as peças que você pode tocar.
- **Software** é a parte lógica: os programas, ou seja, as instruções que dizem ao hardware o que fazer.

Um celular, um notebook e um videogame são todos computadores. Mudam o tamanho e o formato, mas as peças principais são as mesmas.

## As peças principais

Uma boa comparação é uma cozinha.

| Peça | O que faz | Na cozinha |
| --- | --- | --- |
| **Processador** (CPU) | Executa as instruções dos programas, uma a uma, muito rápido | O cozinheiro |
| **Memória RAM** | Guarda o que está sendo usado agora | A bancada de trabalho |
| **Armazenamento** (SSD ou HD) | Guarda arquivos e programas de forma permanente | A despensa |
| **Placa-mãe** | Liga todas as peças entre si | A própria cozinha |

O cozinheiro trabalha com o que está na bancada. Buscar algo na despensa demora mais, e a bancada tem espaço limitado.

## RAM não é armazenamento

Essa é a confusão mais comum.

- A **RAM** é rápida, mas **temporária**. Quando o computador é desligado, tudo o que estava nela se apaga. É por isso que um trabalho não salvo se perde quando falta luz.
- O **armazenamento** é mais lento, mas **permanente**. Salvar um arquivo é copiá-lo da RAM para o armazenamento.

Quando se abrem programas demais, a RAM enche e o computador fica lento: a bancada ficou sem espaço.

## Entrada e saída

O computador se comunica com o mundo por meio de dispositivos:

- **De entrada**, que levam informação para dentro: teclado, mouse, microfone, câmera.
- **De saída**, que trazem informação para fora: tela, alto-falante, impressora.

Alguns fazem as duas coisas. A tela sensível ao toque do celular mostra a imagem (saída) e recebe os toques (entrada).

## O sistema operacional

O **sistema operacional** é o programa que administra todo o resto. Ele controla o hardware, organiza os arquivos, decide quanto do processador e da memória cada programa pode usar e oferece a interface que você vê.

Os mais conhecidos são **Windows**, **macOS** e **Linux** nos computadores, e **Android** e **iOS** nos celulares.

Os outros programas, como navegadores, editores de texto e jogos, são chamados de **aplicativos**. Eles pedem ao sistema operacional tudo de que precisam: "abra este arquivo", "mostre isto na tela", "envie isto pela rede".

## Exemplo resolvido

**Você está digitando um texto no celular, sem salvar, e a bateria acaba. O que aconteceu com o texto?**

1. Pense na cozinha da aula. O texto que você digita está na **bancada**, a memória RAM, que guarda o que está sendo usado agora.
2. A RAM é rápida, mas **temporária**: quando o aparelho desliga, o que estava nela se apaga.
3. O **armazenamento** é a despensa: guarda de forma permanente. Salvar um arquivo é copiá-lo da RAM para o armazenamento.
4. Como você não salvou, nada foi copiado para a despensa. Ao desligar, a bancada foi limpa, e o texto se perdeu.
5. Solução: salve de tempos em tempos, e use programas que salvam sozinhos.

Segunda pergunta: o computador ficou lento com programas demais abertos. Por quê? A RAM enche (a bancada ficou sem espaço), e o processador (o cozinheiro) não tem onde trabalhar.

## Resumo

- Hardware é a parte física; software são os programas, as instruções que dizem ao hardware o que fazer.
- Processador executa as instruções; memória RAM guarda o que está em uso agora; armazenamento (SSD ou HD) guarda de forma permanente; placa-mãe liga tudo.
- RAM não é armazenamento: a RAM é rápida e temporária (apaga ao desligar); salvar é copiar da RAM para o armazenamento.
- Dispositivos de entrada levam informação para dentro (teclado, mouse, microfone); os de saída trazem para fora (tela, alto-falante).
- O sistema operacional (Windows, macOS, Linux, Android, iOS) administra o hardware, organiza os arquivos e oferece a interface; os aplicativos pedem a ele o que precisam.
