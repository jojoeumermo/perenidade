> **Para quem acompanha:** se puder, saiam juntos para a rua e leiam as placas de verdade. Fotografar placas com o celular e ler depois em casa também ajuda.

## Palavras que estão em todo lugar

Muita gente que não lê reconhece placas pela cor e pelo desenho. Agora, vamos ler as palavras.

| Placa | O que quer dizer |
| --- | --- |
| **ENTRADA** | por onde se entra |
| **SAÍDA** | por onde se sai |
| **PARE** | o carro tem de parar |
| **PERIGO** | cuidado, risco |
| **PROIBIDO** | não pode |
| **PUXE** / **EMPURRE** | puxe a porta / empurre a porta |
| **FECHADO** / **ABERTO** | a loja está fechada / aberta |
| **BANHEIRO** | sanitário |
| **FARMÁCIA** | onde se compram remédios |
| **POSTO DE SAÚDE** | unidade de saúde |

## O ônibus

No letreiro aparecem o **número** da linha e o **destino**:

**125 — CENTRO**

**340 — TERMINAL NORTE**

Às vezes aparece **VIA**, que quer dizer "passando por":

**340 — TERMINAL NORTE VIA HOSPITAL**

```verificar
O letreiro diz "210 — RODOVIÁRIA VIA CENTRO". Para onde vai o ônibus?
+ Para a rodoviária, passando pelo centro
- Para o centro, passando pela rodoviária
- Para a garagem
> VIA quer dizer "passando por".
```

## A conta de luz e de água

As contas têm muitas informações. As mais importantes:

| Palavra | O que quer dizer |
| --- | --- |
| **VENCIMENTO** | último dia para pagar sem multa |
| **VALOR A PAGAR** / **TOTAL** | quanto pagar |
| **CONSUMO** | quanto você gastou de luz ou de água |
| **LEITURA** | o número do relógio medidor |
| **MÊS DE REFERÊNCIA** | o mês da conta |
| **MULTA** / **JUROS** | o que se cobra a mais pelo atraso |

Conferir a conta é um direito. Se o valor vier muito diferente do normal, procure a empresa ou o Procon.

Famílias de baixa renda inscritas no Cadastro Único podem ter desconto na conta de luz, a **Tarifa Social**. Pergunte no CRAS do seu bairro.

## Para praticar

1. Tire fotos de três placas do seu bairro e leia com alguém.
2. Pegue uma conta de luz ou de água e encontre: VENCIMENTO, VALOR, CONSUMO.
3. Escreva o número e o destino do ônibus que você mais usa.
4. Escreva duas palavras de placa que você já reconhece.
