## Línguas próximas, armadilhas sutis

A proximidade entre o português e o espanhol ajuda muito, e também engana: como quase tudo parece igual, as diferenças passam despercebidas. A mistura das duas línguas tem até nome: **portunhol**. Nas fronteiras, ele é uma forma viva e legítima de comunicação. Em uma tradução ou em um texto formal, é sinal de descuido.

## 1. Falsos amigos

Palavras parecidas com sentidos diferentes: *embarazada* (grávida), *exquisito* (delicioso), *oficina* (escritório), *rato* (momento), *todavía* (ainda). Veja a lista em [Falsos amigos entre português e espanhol](/trilhas/espanhol-do-zero/falsos-amigos-entre-portugues-e-espanhol).

## 2. Gênero diferente

*La leche*, *la sal*, *la nariz*, *el puente*, *el árbol*, *el color*. Veja [Artigos e gênero das palavras](/trilhas/espanhol-do-zero/artigos-e-genero-das-palavras).

## 3. Tonicidade diferente

Palavras escritas quase igual, com a sílaba tônica em outro lugar:

| Português | Espanhol |
| --- | --- |
| polícia | policía |
| democracia | democracia (de-mo-**cra**-cia) |
| álcool | alcohol (al-co-**hol**) |
| nível | nivel (ni-**vel**) |
| cérebro | cerebro (ce-**re**-bro) |
| limite | límite |
| oceano | océano |
| alergia | alergia (a-**ler**-gia) |

## 4. Regências e preposições

| Espanhol | Português |
| --- | --- |
| ir **a** | ir **a** (no Brasil, muitas vezes "ir em") |
| casarse **con** | casar-se **com** |
| soñar **con** | sonhar **com** |
| enamorarse **de** | apaixonar-se **por** |
| llamar **a** alguien | chamar, ligar para alguém |
| ayudar **a** + infinitivo | ajudar **a** |
| ver **a** María | ver Maria (o espanhol usa *a* antes de objeto direto de pessoa) |

Esse último caso é importante: em espanhol, o objeto direto **de pessoa** leva **a**: *Conozco **a** tu hermano. Llamé **a** la directora.*

## 5. Expressões idiomáticas

| Espanhol | Português |
| --- | --- |
| hacer falta | ser preciso, faltar |
| tomar el pelo | zoar, enganar |
| estar en las nubes | estar no mundo da lua |
| dar igual | tanto faz |
| echar de menos | sentir saudade |
| ponerse las pilas | se esforçar, se mexer |
| costar un ojo de la cara | custar os olhos da cara |

```verificar
Como se traduz "Echo de menos a mi familia"?
- Jogo menos a minha família
+ Sinto saudade da minha família
- Tenho menos família
> Echar de menos é uma expressão fixa.
```

## 6. Pronomes e estrutura

- O espanhol usa os pronomes de objeto com regularidade (*lo vi, se lo di*), enquanto o português do Brasil frequentemente os omite na fala.
- O espanhol prefere **o sujeito oculto** como o português, mas usa o **gerúndio** de forma um pouco diferente: evite traduzir automaticamente "estou fazendo" e "vou estar fazendo".
- Em espanhol, não existe a construção "a gente" para "nós": use *nosotros*.

## Estratégias

1. Desconfie do que parece **fácil demais**.
2. Leia a tradução **em voz alta**, para perceber tonicidade e ritmo.
3. Consulte um **dicionário monolíngue** de espanhol para conferir o sentido exato.
4. Peça a um falante nativo que revise textos importantes.
5. Revise com especial cuidado **números, datas, nomes próprios e termos técnicos**.

## Para praticar

1. Traduza: "Conocí a tu prima ayer." / "Me hace falta un abrigo." / "Me tomaron el pelo."
2. Pronuncie corretamente: policía, alcohol, nivel, democracia, océano.
3. Traduza para o espanhol, cuidando das preposições: "Casei com ela em 2010." / "Sonhei com você."
4. Encontre, em um texto traduzido do espanhol, um trecho que soe como portunhol e proponha uma tradução melhor.
