## Os artigos

| | Masculino | Feminino |
| --- | --- | --- |
| Definido singular | **el** | **la** |
| Definido plural | **los** | **las** |
| Indefinido singular | **un** | **una** |
| Indefinido plural | **unos** | **unas** |

Atenção: o artigo masculino singular é **el**, sem acento. **Él**, com acento, é o pronome "ele".

## Contrações

Só existem duas:

- **a + el = al**: *Voy al trabajo.* Vou ao trabalho.
- **de + el = del**: *Vengo del mercado.* Venho do mercado.

O espanhol **não** contrai preposição e artigo como o português faz em "no", "na", "pelo", "num": *en el banco* (no banco), *en la calle* (na rua), *por la mañana* (pela manhã).

## O artigo neutro lo

**Lo** + adjetivo transforma a qualidade em ideia geral:

- *Lo bueno es que...* O bom é que...
- *Lo importante es participar.* O importante é participar.
- *Lo que dijiste.* O que você disse.

## El agua

Palavras **femininas** que começam com **a tônica** (ou **ha** tônica) usam **el** no singular, para evitar o encontro de dois "a": *el agua*, *el arma*, *el hambre*, *el águila*. Continuam femininas: *el agua fría*, *las aguas*.

## Palavras com gênero diferente

São os chamados **heterogenéricos**: armadilhas para quem fala português.

| Espanhol | Português |
| --- | --- |
| **la** leche | **o** leite |
| **la** sal | **o** sal |
| **la** sangre | **o** sangue |
| **la** nariz | **o** nariz |
| **la** miel | **o** mel |
| **la** costumbre | **o** costume |
| **la** señal | **o** sinal |
| **el** árbol | **a** árvore |
| **el** puente | **a** ponte |
| **el** color | **a** cor |
| **el** dolor | **a** dor |
| **el** origen | **a** origem |
| **el** equipo | **a** equipe |

Em espanhol, as palavras terminadas em **-aje** são masculinas (*el viaje, el mensaje, el paisaje*), e as terminadas em **-umbre**, femininas (*la costumbre, la cumbre*).

```verificar
Qual frase está correta?
- El leche está frío.
+ La leche está fría.
- Lo leche está fría.
> Leche é feminino em espanhol.
```

## Para praticar

1. Escreva o artigo definido: ___ viaje, ___ nariz, ___ árbol, ___ sangre, ___ agua, ___ mensaje.
2. Complete com al ou del: "Voy ___ hospital." / "Salgo ___ trabajo a las seis."
3. Traduza: "no ônibus", "na escola", "pela tarde".
4. Escreva três frases começando com *Lo importante es...*
