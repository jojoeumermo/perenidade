## O que é coesão

**Coesão** é a ligação entre as partes do texto: palavras, frases, parágrafos. Um texto coeso se lê com fluidez, e o leitor entende como cada ideia se relaciona com a anterior.

## Os conectivos

| Relação | Conectivos |
| --- | --- |
| **Adição** | além disso, ademais, também, não só... mas também |
| **Oposição** | no entanto, contudo, entretanto, todavia, porém, mas |
| **Concessão** | embora, ainda que, apesar de |
| **Causa** | porque, visto que, uma vez que, já que |
| **Consequência** | portanto, logo, assim, por isso, dessa forma |
| **Exemplo** | por exemplo, como, a exemplo de |
| **Finalidade** | para que, a fim de |
| **Conclusão** | em suma, portanto, dessa maneira, diante disso |
| **Sequência** | em primeiro lugar, em seguida, por fim |

O conectivo precisa expressar a **relação lógica correta**. Usar "portanto" antes de uma ideia que se opõe à anterior é um erro.

## Entre parágrafos

Cada parágrafo de desenvolvimento deve começar ligado ao anterior:

- *Em primeiro lugar, ...*
- *Além disso, ...* / *Outro fator relevante é ...*
- *Diante desse cenário, ...* (na conclusão)

## As retomadas

Para não repetir a mesma palavra, retome-a com:

- **pronomes**: *ele, ela, isso, esse, essa, o qual*;
- **sinônimos**: *o governo* → *o Estado*, *o poder público*;
- **expressões**: *as mulheres* → *essa parcela da população*;
- **elipse**: omitir o que já está claro.

```conta
Repetitivo: "O trabalho de cuidado é invisível. O trabalho de cuidado não é pago. O trabalho de cuidado é feito pelas mulheres."
Coeso: "O trabalho de cuidado é invisível: não é remunerado e, além disso, recai sobretudo sobre as mulheres."
```

```verificar
Qual conectivo completa melhor: "A Constituição garante o direito à moradia. ___, milhões de famílias vivem em condições precárias."
+ No entanto
- Portanto
- Além disso
> A segunda ideia contrasta com a primeira.
```

## Cuidados

- Não use conectivos em **excesso**, em todas as frases.
- Varie os conectivos: repetir "além disso" em todo parágrafo empobrece o texto.
- Garanta que os **pronomes** tenham referência clara: "isso" refere-se a quê?

## Para praticar

1. Reescreva o trecho repetitivo de um texto seu usando retomadas.
2. Classifique: contudo, visto que, ademais, a fim de, em suma.
3. Escreva dois parágrafos ligados por um conectivo de oposição.
4. Circule todos os conectivos de uma redação nota 1 000 da cartilha do Inep.
