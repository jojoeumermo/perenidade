## Propor uma saída

A **Competência 5** avalia a **proposta de intervenção**: a solução que você apresenta para o problema discutido. Ela costuma vir na **conclusão** e deve estar **ligada aos argumentos**.

## Os cinco elementos

| Elemento | Pergunta | Exemplo |
| --- | --- | --- |
| **Agente** | quem vai fazer? | o Ministério da Saúde; as escolas; a mídia; o Congresso |
| **Ação** | o que vai ser feito? | criar campanhas; ampliar creches; aprovar uma lei |
| **Meio / modo** | como? | por meio de verbas; em parceria com os municípios |
| **Finalidade** | para quê? | a fim de reduzir a sobrecarga das mulheres |
| **Detalhamento** | um detalhe a mais sobre qualquer elemento | creches em período integral nas periferias |

## Exemplo

> *Diante disso, cabe ao **governo federal** (agente) **ampliar a oferta de creches públicas em período integral** (ação), **por meio de recursos destinados aos municípios com maior déficit de vagas** (meio), **a fim de reduzir a sobrecarga do trabalho de cuidado sobre as mulheres** (finalidade). Essas creches devem priorizar as periferias e as áreas rurais, onde a falta de vagas é maior (detalhamento).*

```verificar
Na proposta "A mídia deve promover campanhas", o que falta para ficar completa?
+ O meio, a finalidade e um detalhamento
- Nada, está completa
- Só o agente
> Pergunte: como? para quê? que detalhe?
```

## Cuidados

- **Agentes concretos**: "a sociedade" e "todos" são vagos. Prefira instituições: ministérios, escolas, ONGs, mídia, sindicatos, movimentos sociais.
- **Coerência**: a proposta deve responder aos **problemas** apontados nos argumentos.
- **Direitos humanos**: a proposta não pode defender violência, tortura, pena de morte, discriminação ou supressão de direitos. Propostas assim são penalizadas.
- **Viabilidade**: propostas realistas são mais convincentes que soluções mágicas.

## Uma ou duas propostas?

Uma proposta completa já atende à competência. Muitas redações nota máxima apresentam **duas**, uma para cada argumento, o que reforça a coerência.

## Para praticar

1. Escreva uma proposta completa, com os cinco elementos, para o tema de 2020.
2. Identifique os elementos de uma proposta em uma redação nota 1 000.
3. Reescreva uma proposta vaga ("é preciso conscientizar a população") de forma completa.
4. Escreva duas propostas para o tema de 2024, uma para cada argumento.
