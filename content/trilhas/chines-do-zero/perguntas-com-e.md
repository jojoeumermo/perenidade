## Sim ou não: 吗

A forma mais simples de pergunta: a frase afirmativa + **吗** (*ma*, tom neutro).

| Afirmação | Pergunta |
| --- | --- |
| 你是学生。 | 你是学生**吗**？ Você é estudante? |
| 他有孩子。 | 他有孩子**吗**？ Ele tem filhos? |
| 你很忙。 | 你忙**吗**？ Você está ocupado? |

Em chinês não há "sim" e "não" universais. Responde-se repetindo o **verbo**:

- 你是学生吗？— 是。/ 不是。
- 你有孩子吗？— 有。/ 没有。
- 你忙吗？— 忙。/ 不忙。

## Outro jeito: afirmativo-negativo

Repetir o verbo na forma afirmativa e negativa também faz pergunta, **sem 吗**:

- 你是不是学生？*Nǐ shì bu shì xuésheng?* Você é ou não é estudante?
- 你有没有孩子？*Nǐ yǒu méiyǒu háizi?*

## As palavras interrogativas

| Caractere | Pinyin | Sentido |
| --- | --- | --- |
| 什么 | shénme | o quê, qual |
| 谁 | shéi (ou shuí) | quem |
| 哪儿 / 哪里 | nǎr / nǎlǐ | onde |
| 几 | jǐ | quantos (números pequenos) |
| 多少 | duōshao | quantos, quanto |
| 怎么 | zěnme | como |
| 为什么 | wèishénme | por quê |
| 什么时候 | shénme shíhou | quando |
| 哪 | nǎ | qual (+ classificador) |

### A regra de ouro: o lugar da resposta

Em português, a palavra interrogativa costuma ir para o **começo** ("**O que** você come?"). Em chinês, ela fica **no lugar onde estará a resposta**:

| Pergunta | Resposta |
| --- | --- |
| 你吃**什么**？ *Nǐ chī shénme?* (você come o quê?) | 我吃**米饭**。 Eu como arroz. |
| 他是**谁**？ *Tā shì shéi?* (ele é quem?) | 他是**我哥哥**。 Ele é meu irmão. |
| 你住在**哪儿**？ *Nǐ zhù zài nǎr?* (você mora onde?) | 我住在**圣保罗**。 Moro em São Paulo. |
| **谁**是老师？ (quem é o professor?) | **李老师**是老师。 |

E com palavra interrogativa **não se usa 吗**.

```verificar
Como se pergunta "Onde você trabalha?" (trabalhar = 工作, gōngzuò; em = 在, zài)?
- 哪儿你在工作？
+ 你在哪儿工作？
- 你在哪儿工作吗？
> A palavra interrogativa fica onde estará a resposta (我在医院工作 = trabalho no hospital), e não leva 吗.
```

## E você? 呢

**呢** (*ne*) depois de uma palavra devolve a pergunta: "e...?"

- 我很好，你**呢**？ Estou bem, e você?
- 我是巴西人。你**呢**？ Sou brasileiro. E você?

## Quantos: 几 ou 多少

- **几** para quantidades pequenas, esperadas como menores que dez, e sempre com classificador: 你有几个孩子？
- **多少** para quantidades maiores ou desconhecidas, como preços: 这个多少钱？ *Zhège duōshao qián?* Quanto custa isto?

## Para praticar

1. Transforme em pergunta com 吗: 她是医生。/ 你有哥哥。/ 今天很热。
2. Faça a pergunta para cada resposta: 我叫王芳。/ 我住北京。/ 我吃面条。
3. Reescreva as perguntas do exercício 1 na forma afirmativo-negativa.
4. Monte um pequeno diálogo usando 呢.
