```provocacao
"O cachorro morde o homem" e "O homem morde o cachorro": em português, só a ordem diz quem morde. Em alemão, o artigo mostra quem é quem, mesmo trocando a ordem. Como?
```

## O que você vai aprender

Ao fim desta aula você vai reconhecer o acusativo, mudar os artigos masculinos e usar verbos que pedem objeto direto.

## Quatro casos

O alemão tem **quatro casos**: **nominativo, acusativo, dativo e genitivo**. O caso mostra a **função** da palavra na frase. Até agora você usou o **nominativo** (o **sujeito**, quem faz a ação).

O **acusativo** é o caso do **objeto direto**: **quem ou o que recebe a ação**. Pergunta-se **wen?** (quem?) ou **was?** (o quê?).

## Só o masculino muda

| | Nominativo | Acusativo |
| --- | --- | --- |
| masculino | **der / ein** Tisch | **den / einen** Tisch |
| feminino | die / eine Zeitung | die / eine Zeitung |
| neutro | das / ein Buch | das / ein Buch |
| plural | die Bücher | die Bücher |

O mesmo vale para **kein** e para os possessivos: *keinen, meinen, deinen*.

- ***Ich kaufe **einen** Tisch.*** — Eu compro uma mesa.
- ***Ich habe **keinen** Hunger.*** — Não tenho fome.
- ***Ich besuche **meinen** Vater.*** — Visito meu pai.

## Os pronomes também mudam

**ich → mich**, **du → dich**, **er → ihn**, **wir → uns**, **ihr → euch**. *sie, es, Sie* não mudam.

- ***Ich sehe **dich**.*** — Eu vejo você.
- ***Kennst du **ihn**?*** — Você o conhece?

## Quem morde quem

Como o artigo mostra o caso, a ordem pode mudar sem mudar o sentido:

- ***Der Hund beißt **den** Mann.*** — O cachorro morde o homem.
- *****Den** Mann beißt der Hund.*** — (Mesmo sentido: quem é mordido é o homem.)

## Exemplo resolvido

**Escreva a lista de compras em frases: der Kaffee, die Milch, das Brot, die Eier.**

1. ***Ich kaufe **den** Kaffee.*** — masculino: der → **den**.
2. ***Ich kaufe **die** Milch.*** — feminino: não muda.
3. ***Ich kaufe **das** Brot.*** — neutro: não muda.
4. ***Ich kaufe **die** Eier.*** — plural: não muda.

## Resumo

- O alemão tem **quatro casos**; o **acusativo** marca o **objeto direto**.
- **Só o masculino muda**: **der → den**, **ein → einen**, **kein → keinen**, **mein → meinen**.
- Pronomes: **mich, dich, ihn, uns, euch**.
- O artigo mostra a função, por isso a **ordem pode variar**.
