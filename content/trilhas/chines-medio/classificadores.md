## Uma palavra no meio

Em português dizemos "três livros". Em chinês, entre o número e o substantivo é obrigatório um **classificador** (量词, *liàngcí*):

**número + classificador + substantivo**

- 三**本**书 *sān běn shū* — três livros;
- 两**个**人 *liǎng ge rén* — duas pessoas;
- 一**张**桌子 *yì zhāng zhuōzi* — uma mesa.

O português tem algo parecido em "duas **folhas** de papel", "uma **cabeça** de gado", "três **pés** de alface". Em chinês, isso vale para quase tudo.

O mesmo acontece depois de **这** (*zhè*, este) e **那** (*nà*, aquele): 这**本**书 (este livro), 那**个**人 (aquela pessoa).

## Os mais frequentes

| Classificador | Pinyin | Usado para | Exemplos |
| --- | --- | --- | --- |
| 个 | gè | uso geral; pessoas | 一个人, 三个苹果 |
| 本 | běn | livros, cadernos | 两本书 |
| 张 | zhāng | coisas planas | 一张纸, 一张票 (ingresso), 一张床 |
| 条 | tiáo | coisas longas e flexíveis | 一条路 (rua), 一条河 (rio), 一条鱼 |
| 只 | zhī | muitos animais; um de um par | 一只猫 (gato), 一只手 (uma mão) |
| 件 | jiàn | roupas de cima; assuntos | 一件衣服, 一件事 (um assunto) |
| 辆 | liàng | veículos | 一辆车 |
| 杯 | bēi | copo, xícara | 一杯水 |
| 位 | wèi | pessoas (respeitoso) | 一位老师 |
| 家 | jiā | empresas, lojas | 一家公司, 一家医院 |
| 口 | kǒu | membros da família | 五口人 |
| 双 | shuāng | pares | 一双鞋 (um par de sapatos) |

Há uma **lógica de forma**: 条 para o que é comprido (rua, rio, peixe, calça); 张 para o que é plano (papel, foto, mesa, cama, cartão).

## Perguntas

- 几 + classificador: 你有几**本**书？ Quantos livros você tem?
- 哪 + classificador: 你要哪**个**？ Qual você quer?

## Sem número

Depois de 这 e 那, o número 一 costuma ser omitido: 这本书 = este (um) livro. Para o plural, usa-se **些** (*xiē*): 这些书 (estes livros), 那些人 (aquelas pessoas).

```verificar
Como se diz "duas ruas"?
- 两个路
+ 两条路
- 二条路
> Rua é longa (条) e, antes de classificador, o dois é 两.
```

## O classificador de reserva

**个** é o mais geral, e muitos falantes o usam no lugar de classificadores específicos na fala informal. Para quem está aprendendo, é melhor usar 个 do que nada. Mas o caminho é aprender o classificador junto com cada substantivo, como se aprende o gênero das palavras em português.

## Para praticar

1. Complete com o classificador: 三___书, 一___纸, 两___狗 (cachorro), 一___衣服, 四___车.
2. Descreva o que há na sua mesa, com classificadores.
3. Transforme em plural com 些: 这本书, 那个人.
4. Faça três perguntas com 几 + classificador.
