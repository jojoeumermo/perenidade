## O que você vai aprender

Ao fim desta aula você vai saber o que é uma reação em equilíbrio, escrever e ler a constante de equilíbrio e prever, pelo princípio de Le Chatelier, para onde o equilíbrio vai quando se muda a concentração, a pressão ou a temperatura.

## Reações que vão e voltam

Muitas reações não vão até o fim. Os produtos que se formam também reagem entre si e refazem os reagentes. Escreve-se com duas setas: ⇌.

No refrigerante fechado, há gás carbônico no espaço do gargalo e gás carbônico dissolvido no líquido. O gás se dissolve e o dissolvido escapa, ao mesmo tempo. Quando as duas velocidades se igualam, as quantidades param de mudar. É o **equilíbrio químico**.

Atenção: parar de mudar não é parar de reagir. O equilíbrio é **dinâmico**. As duas reações continuam, só que com a mesma velocidade, e uma desfaz o que a outra faz.

## A constante de equilíbrio

Para cada reação, numa temperatura fixa, existe um número que resume o equilíbrio: a constante Kc.

```formula
Kc = [produtos]^coeficientes ÷ [reagentes]^coeficientes
os colchetes são as concentrações em mol/L, já no equilíbrio
cada concentração vai elevada ao coeficiente da equação; sólidos e líquidos puros ficam de fora
```

Para aA + bB ⇌ cC + dD, a expressão é Kc = [C]ᶜ · [D]ᵈ ÷ ([A]ᵃ · [B]ᵇ).

Como ler o número:

- **Kc muito maior que 1:** no equilíbrio há muito mais produto. A reação "vai longe".
- **Kc muito menor que 1:** no equilíbrio sobra muito reagente. A reação "anda pouco".

Kc só muda com a temperatura. Mudar concentração ou pressão desloca o equilíbrio, mas o novo equilíbrio tem o mesmo Kc.

Um cuidado: Kc grande diz para onde o equilíbrio pende, não quão depressa ele chega lá. Uma reação pode ter Kc enorme e ser lentíssima. Velocidade é assunto da cinética; o equilíbrio fala só do ponto de chegada.

## O princípio de Le Chatelier

O químico francês Henri Le Chatelier resumiu o comportamento dos equilíbrios numa regra: quando se perturba um sistema em equilíbrio, ele se desloca no sentido de diminuir a perturbação.

```formula
perturbação → o equilíbrio anda para "desfazer" a perturbação
pôs mais de uma substância: o equilíbrio anda para consumi-la
tirou uma substância: o equilíbrio anda para repô-la
```

**Concentração.** Acrescentar reagente desloca para os produtos. Retirar produto também desloca para os produtos, para repor o que saiu. É assim que uma fábrica tira o produto aos poucos e a reação continua.

**Pressão (só para gases).** Aumentar a pressão desloca para o lado com **menos mols de gás**, que ocupa menos espaço. Diminuir a pressão desloca para o lado com mais mols. Se os dois lados têm o mesmo número de mols de gás, a pressão não desloca nada.

**Temperatura.** Pense no calor como se fosse um reagente ou um produto.

- Reação **exotérmica** (libera calor, ΔH < 0): o calor é "produto". Aquecer desloca para os reagentes; esfriar, para os produtos.
- Reação **endotérmica** (absorve calor, ΔH > 0): o calor é "reagente". Aquecer desloca para os produtos.

A temperatura é a única perturbação que muda o valor de Kc.

**Catalisador** não desloca. Ele acelera as duas reações igualmente: o equilíbrio chega antes, mas no mesmo ponto.

```navidareal
Volte ao refrigerante da provocação. Na garrafa fechada, há o equilíbrio CO₂(gás) ⇌ CO₂(dissolvido), sob pressão alta. Ao abrir, o gás do gargalo escapa e a pressão cai.

Pelo princípio de Le Chatelier, o equilíbrio anda para o lado do gás, para repor o que saiu. O gás dissolvido vira bolha. Na geladeira, o refrigerante perde menos gás: a dissolução do CO₂ libera calor, e o frio favorece o lado dissolvido.
```

```verificar
Na reação exotérmica 2 SO₂(g) + O₂(g) ⇌ 2 SO₃(g), aquecer o sistema desloca o equilíbrio para
- os produtos
+ os reagentes
- nenhum lado
> Na reação exotérmica o calor é como um produto. Pôr mais calor faz o equilíbrio andar para consumi-lo: para o lado dos reagentes.
```

## Exemplo resolvido

**No equilíbrio N₂O₄(g) ⇌ 2 NO₂(g), as concentrações são [N₂O₄] = 0,1 mol/L e [NO₂] = 0,2 mol/L. Calcule Kc.**

1. Escreva a expressão: Kc = [NO₂]² ÷ [N₂O₄]. O NO₂ vai ao quadrado porque o coeficiente é 2.
2. Substitua: Kc = (0,2)² ÷ 0,1 = 0,04 ÷ 0,1.
3. Resultado: Kc = 0,4.

Confira: Kc menor que 1 quer dizer que, nessa temperatura, o equilíbrio não favorece muito o NO₂. Quem esquece o expoente acha 0,2 ÷ 0,1 = 2, o que daria uma leitura oposta.

Este tópico teve 2 delas: em 2022, o excesso de H⁺ num solo ácido empurrando a amônia a virar amônio; em 2023, uma substância que prende o alumínio dissolvido fazendo mais alumínio sair do vidro. São só duas edições: é tendência, não promessa.
- **Habilidades:** H17 (relacionar informações em texto, gráfico, tabela ou fórmula), com 6 das 89 questões de Natureza nessa base; H24 (usar a linguagem da química), a mais frequente, com 11; e H9 (entender os ciclos biogeoquímicos), quando o equilíbrio está no ciclo do nitrogênio.
- **Armadilhas:**
  - Achar que, no equilíbrio, a reação parou ou que reagentes e produtos têm a mesma quantidade.
  - Achar que o catalisador desloca o equilíbrio.
  - Pôr sólidos e líquidos puros na expressão de Kc.
  - Esquecer os expoentes em Kc.
  - Na pressão, contar todos os mols, inclusive de sólidos e líquidos. Só os gases contam.

## Questão comentada

**Texto-base.** A amônia, matéria-prima de fertilizantes, é produzida a partir do nitrogênio do ar e do hidrogênio:

N₂(g) + 3 H₂(g) ⇌ 2 NH₃(g)    ΔH < 0 (exotérmica)

Uma fábrica quer aumentar a quantidade de amônia no equilíbrio.

**Comando.** Uma mudança que desloca esse equilíbrio no sentido da amônia é

A) diminuir a pressão do reator.
B) aumentar a pressão do reator.
C) aquecer o reator a uma temperatura muito mais alta.
D) acrescentar um catalisador.
E) acrescentar amônia ao reator.

**Resolução.**

1. Conte os mols de gás: à esquerda, 1 + 3 = 4; à direita, 2.
2. Aumentar a pressão desloca para o lado com menos mols de gás: o da amônia.
3. A reação é exotérmica. Aquecer deslocaria para os reagentes, o contrário do desejado.

**Gabarito: B.**

**Por que as outras não:**

- A) Diminuir a pressão favorece o lado com mais mols de gás, o dos reagentes.
- C) Em reação exotérmica, aquecer desloca para os reagentes. (Na prática, a indústria usa temperatura moderada para a reação não ficar lenta demais: é um meio-termo entre velocidade e rendimento.)
- D) O catalisador faz o equilíbrio chegar antes, mas não muda onde ele fica.
- E) Acrescentar produto desloca para os reagentes, para consumir a amônia posta.

```realidade
Abra duas garrafas pequenas de água com gás, uma gelada e outra em temperatura ambiente, e despeje cada uma num copo. Qual faz mais espuma? Explique com o princípio de Le Chatelier.
```

## Resumo

- Equilíbrio é dinâmico: as reações direta e inversa seguem, com a mesma velocidade.
- Kc = produtos ÷ reagentes, com expoentes; sólidos e líquidos puros ficam fora.
- Kc > 1: favorece produtos; Kc < 1: favorece reagentes. Só a temperatura muda Kc.
- Le Chatelier: o equilíbrio anda para diminuir a perturbação.
- Mais pressão: lado com menos mols de gás. Exotérmica aquecida: reagentes.
- Catalisador não desloca o equilíbrio.
