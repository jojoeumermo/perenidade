## O que você vai aprender

Ao fim desta aula você vai conhecer os seis casos do russo, a função de cada um e a pergunta que ajuda a reconhecê-lo.

## Seis casos

Em russo, substantivos, pronomes e adjetivos **mudam a terminação** conforme a **função** na frase. São **seis casos**:

| Caso | Função principal | Pergunta | Exemplo com **мáма** |
| --- | --- | --- | --- |
| **Nominativo** | sujeito | кто? что? (quem? o quê?) | **Мáма** рабóтает. — A mãe trabalha. |
| **Genitivo** | posse, ausência, "de" | когó? чегó? (de quem? de quê?) | Э́то дом **мáмы**. — É a casa da mãe. |
| **Dativo** | "para", "a" (objeto indireto) | комý? чемý? (a quem?) | Я звоню́ **мáме**. — Telefono para a mãe. |
| **Acusativo** | objeto direto, direção | когó? что? (quem? o quê?) | Я люблю́ **мáму**. — Amo a mãe. |
| **Instrumental** | "com", instrumento | кем? чем? (com quem? com o quê?) | Я гуля́ю с **мáмой**. — Passeio com a mãe. |
| **Preposicional** | lugar, assunto (sempre com preposição) | о ком? где? (sobre quem? onde?) | Я дýмаю о **мáме**. — Penso na mãe. |

## A preposição escolhe o caso

Muitas preposições pedem um caso fixo:

- **в / на** + **preposicional** = lugar (onde?): *в Москвé, на рабóте* (em Moscou, no trabalho)
- **в / на** + **acusativo** = direção (para onde?): *в Москвý, на рабóту*
- **у** + **genitivo**: *у меня́* (comigo, "tenho")
- **с** + **instrumental**: *с дрýгом* (com o amigo)

## Uma palavra masculina

**стол** (mesa): стол (nom.), столá (gen.), столý (dat.), стол (ac.), столóм (instr.), о столé (prep.).

```verificar
Em "Я иду на работу" (Vou para o trabalho), em que caso está работу?
- Preposicional
+ Acusativo, porque indica direção
- Nominativo
> на + acusativo = para onde; на + preposicional = onde.
```

## Exemplo resolvido

**Identifique o caso de cada palavra em negrito: "У **сестры́** нет **машины**, поэтому она ездит на работу на **автобусе** с **подругой**."** (Minha irmã não tem carro, por isso vai ao trabalho de ônibus com uma amiga.)

1. **сестры́** → depois de **у** → **genitivo**
2. **маши́ны** → depois de **нет** (não há) → **genitivo** (ausência)
3. **рабóту** → **на** + direção → **acusativo**
4. **автóбусе** → **на** + meio de transporte (lugar) → **preposicional**
5. **подрýгой** → **с** (com) → **instrumental**

## Resumo

- Seis casos: **nominativo, genitivo, dativo, acusativo, instrumental, preposicional**.
- Cada um tem uma **função** e uma **pergunta**.
- **Preposições** pedem casos fixos (в/на, у, с...).
- **в/на + preposicional** = onde; **в/на + acusativo** = para onde.
