## O que você vai aprender

Ao fim desta aula você vai conhecer os pronomes pessoais do alemão e conjugar o verbo **sein** (ser, estar) para se descrever e descrever outras pessoas.

## Os pronomes pessoais

| Alemão | Pronúncia aproximada | Português |
| --- | --- | --- |
| **ich** | ich (com um "ch" chiado, como um gato) | eu |
| **du** | du | você (informal) |
| **er** | ér | ele |
| **sie** | zí | ela |
| **es** | és | "ele/ela" para coisas neutras |
| **wir** | vír | nós |
| **ihr** | ír | vocês (informal) |
| **sie** | zí | eles, elas |
| **Sie** | zí | o senhor, a senhora, os senhores (formal) |

O **Sie** formal é sempre com **maiúscula**, em qualquer lugar da frase.

## O verbo sein

O verbo **sein** é **irregular** (não segue o modelo comum). Serve para **ser** e para **estar**:

| Pessoa | sein |
| --- | --- |
| ich | **bin** |
| du | **bist** |
| er / sie / es | **ist** |
| wir | **sind** |
| ihr | **seid** |
| sie / Sie | **sind** |

- ***Ich bin Lehrerin.*** — Eu sou professora.
- ***Du bist müde.*** — Você está cansado.
- ***Er ist aus Angola.*** — Ele é de Angola.
- ***Wir sind Kollegen.*** — Nós somos colegas.
- ***Sind Sie Frau Silva?*** — A senhora é a senhora Silva?

## Profissões e origem

Em alemão, ao dizer a profissão, **não se usa artigo**: ***Ich bin Krankenpfleger.*** (Eu sou enfermeiro.) Muitas profissões têm forma masculina e feminina; a feminina costuma terminar em **-in**: *Lehrer / Lehrerin* (professor / professora), *Arbeiter / Arbeiterin* (operário / operária).

```verificar
Complete: "Wir ___ aus Brasilien."
- bin
- ist
+ sind
> Com wir (nós), o verbo sein fica sind.
```

## Exemplo resolvido

**Apresente três pessoas da sua família usando sein.**

1. ***Das ist meine Mutter.*** (Esta é minha mãe.) ***Sie ist Köchin.*** (Ela é cozinheira.)
2. ***Das ist mein Bruder.*** (Este é meu irmão.) ***Er ist 20.*** (Ele tem 20 anos — em alemão, a idade se diz com *sein*.)
3. ***Wir sind aus Belém.*** (Nós somos de Belém.)

Repare: *meine* com palavra feminina (Mutter) e *mein* com masculina (Bruder). Isso aparece de novo na aula sobre artigos.

## Resumo

- Pronomes: **ich, du, er, sie, es, wir, ihr, sie, Sie**.
- **sein** = ser e estar: **bin, bist, ist, sind, seid, sind**.
- **Sie** formal é sempre com **maiúscula**.
- Profissão sem artigo: ***Ich bin Lehrer.***
