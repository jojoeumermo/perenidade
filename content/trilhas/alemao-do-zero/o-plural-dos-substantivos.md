```provocacao
Um carro, dois carros. Uma mulher, duas mulheres. Em português, quase sempre basta um "s". Em alemão, há pelo menos cinco jeitos. Como não se perder?
```

## O que você vai aprender

Ao fim desta aula você vai reconhecer os principais jeitos de formar o plural em alemão e usar o artigo plural.

## Os cinco jeitos

Os plurais em alemão se formam normalmente com **-e, -en, -er** ou **sem terminação**, e às vezes a vogal ganha **trema** (ä, ö, ü). Palavras recentes vindas do **inglês e do francês** costumam usar **-s**.

| Jeito | Singular | Plural |
| --- | --- | --- |
| **-e** (às vezes com trema) | der Tag (o dia) | die Tag**e** |
| | die Hand (a mão) | die H**ä**nd**e** |
| **-(e)n** | die Frau (a mulher) | die Frau**en** |
| | die Straße (a rua) | die Straße**n** |
| **-er** (com trema se possível) | das Kind (a criança) | die Kind**er** |
| | das Haus (a casa) | die H**ä**us**er** |
| **sem terminação** (às vezes trema) | der Lehrer (o professor) | die Lehrer |
| | der Vater (o pai) | die V**ä**ter |
| **-s** | das Auto (o carro) | die Auto**s** |
| | das Handy (o celular) | die Handy**s** |

## Tendências que ajudam

- Muitas palavras **femininas** fazem o plural com **-(e)n**: *die Zeitung → die Zeitungen*.
- Palavras terminadas em **-er, -el, -en** (masculinas e neutras) muitas vezes **não mudam**: *der Arbeiter → die Arbeiter*.
- Palavras com **-in** (profissões femininas) dobram o n: *die Lehrerin → die Lehrerinnen*.

## Aprenda em trio

Como não há regra para tudo, aprenda **artigo + singular + plural** juntos: **der Tag, die Tage**. Os dicionários mostram assim.

```verificar
Qual é o plural de "die Arbeiterin" (a operária)?
- die Arbeiterins
+ die Arbeiterinnen
- die Arbeiter
> Palavras femininas em -in fazem o plural com -innen.
```

## Exemplo resolvido

**Transforme a frase para o plural: "Das Kind ist in der Schule." (A criança está na escola.)**

1. **Artigo**: das → **die** (plural).
2. **Substantivo**: Kind → **Kinder**.
3. **Verbo**: ist → **sind** (eles estão).
4. **Resultado**: ***Die Kinder sind in der Schule.*** (As crianças estão na escola.)

## Resumo

- Plurais com **-e, -en, -er, sem terminação ou -s**, às vezes com **trema**.
- Femininas costumam usar **-(e)n**; palavras do inglês, **-s**.
- No plural, o artigo é sempre **die**.
- Aprenda **artigo + singular + plural**.
