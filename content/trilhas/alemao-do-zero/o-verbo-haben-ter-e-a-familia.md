```provocacao
Família não é só pai, mãe e filhos: tem avó que cria, tia que ajuda, vizinha que é quase irmã. Como falar da sua família em outra língua?
```

## O que você vai aprender

Ao fim desta aula você vai conjugar o verbo **haben** (ter), conhecer as palavras da família e falar de quem mora com você.

## O verbo haben

| Pessoa | haben |
| --- | --- |
| ich | **habe** |
| du | **hast** |
| er / sie / es | **hat** |
| wir | **haben** |
| ihr | **habt** |
| sie / Sie | **haben** |

- ***Ich habe zwei Kinder.*** — Eu tenho dois filhos.
- ***Hast du Zeit?*** — Você tem tempo?
- ***Sie hat Hunger.*** — Ela está com fome (literalmente, "tem fome").

## A família

| Alemão | Português |
| --- | --- |
| **die Familie** | a família |
| **die Mutter / der Vater** | a mãe / o pai |
| **die Eltern** | os pais (pai e mãe) |
| **die Tochter / der Sohn** | a filha / o filho |
| **die Kinder** | os filhos, as crianças |
| **die Schwester / der Bruder** | a irmã / o irmão |
| **die Geschwister** | os irmãos (juntos) |
| **die Großmutter (Oma) / der Großvater (Opa)** | a avó / o avô |
| **die Tante / der Onkel** | a tia / o tio |
| **der Partner / die Partnerin** | o companheiro / a companheira |

## Meu e seu

Os possessivos **mein** (meu) e **dein** (seu, informal) ganham **-e** com palavras **femininas** e no **plural**:

- ***mein Vater, mein Kind*** (masculino, neutro)
- ***meine Mutter, meine Kinder*** (feminino, plural)
- ***Das ist dein Bruder?*** — Esse é o seu irmão?

```verificar
Complete: "___ Schwester wohnt in Berlin." (Minha irmã mora em Berlim.)
- Mein
+ Meine
- Meinen
> Schwester é feminina (die), então: meine.
```

## Exemplo resolvido

**Apresente a sua família em quatro frases.**

1. ***Ich habe eine Tochter und einen Sohn.*** (Eu tenho uma filha e um filho.)
   → Repare: com **haben**, o masculino *ein* vira **einen** (é o caso acusativo, que você verá no nível básico).
2. ***Meine Mutter wohnt bei mir.*** (Minha mãe mora comigo.)
3. ***Mein Bruder hat drei Kinder.*** (Meu irmão tem três filhos.)
4. ***Wir sind eine große Familie.*** (Somos uma família grande.)

## Resumo

- **haben** = ter: **habe, hast, hat, haben, habt, haben**.
- Família: **Mutter, Vater, Eltern, Kinder, Geschwister, Oma, Opa**.
- **mein/dein** + **-e** com femininas e plural: *meine Mutter, meine Kinder*.
