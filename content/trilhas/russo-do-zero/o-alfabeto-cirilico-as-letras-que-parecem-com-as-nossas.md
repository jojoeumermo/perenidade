```provocacao
Você chega numa estação e lê "PECTOPAH". Parece uma palavra sem sentido. Em russo, ela diz "restaurante". Como?
```

## O que você vai aprender

Ao fim desta aula você vai reconhecer doze letras do cirílico (as que parecem com as nossas) e ler as primeiras palavras em russo.

## O alfabeto cirílico

O russo é escrito com o **alfabeto cirílico**, que surgiu no **século X** a partir do **alfabeto grego**. O alfabeto russo moderno tem **33 letras**: **20 consoantes**, **10 vogais**, a semivogal **й** e **dois sinais** (ъ e ь), que mudam a pronúncia das letras vizinhas.

## Seis letras quase iguais

| Letra | Som aproximado | Exemplo |
| --- | --- | --- |
| **А а** | a | **МАМА** (mama) — mamãe |
| **Е е** | ie (como em "ieda") | **НЕТ** (niet) — não |
| **К к** | k | **КОТ** (kot) — gato |
| **М м** | m | **МОРЕ** (móre) — mar |
| **О о** | o (quando tônica) | **ТАМ** (tam) — lá |
| **Т т** | t (sempre "t", nunca "tch") | **ТЕАТР** (tiatr) — teatro |

## Seis falsas amigas

Parecem nossas, mas **soam diferente**:

| Letra | Parece | Som | Exemplo |
| --- | --- | --- | --- |
| **В в** | B | **v** | **ВОТ** (vot) — eis aqui |
| **Н н** | H | **n** | **НОС** (nos) — nariz |
| **Р р** | P | **r** vibrante (como em "caro") | **РОТ** (rot) — boca |
| **С с** | C | **s** | **СОК** (sok) — suco |
| **У у** | Y | **u** | **УТРО** (útra) — manhã |
| **Х х** | X | **rr** forte, raspado na garganta | **САХАР** (sákhar) — açúcar |

```verificar
Como se lê РЕСТОРАН?
- Pectopah
+ Restoran (restaurante)
- Rectopan
> Р = r, Е = ie/e, С = s, Т = t, О = o, Р = r, А = a, Н = n.
```

## Exemplo resolvido

**Leia letra por letra a palavra МЕТРО.**

1. **М** = m
2. **Е** = ie / e
3. **Т** = t
4. **Р** = r (falsa amiga!)
5. **О** = o
6. **Resultado**: *metrô*. Na pronúncia real, o **е** sem acento fica perto de "i": **mitró** (isso vem na aula sobre pronúncia).

## Resumo

- O russo usa o **cirílico**: **33 letras**.
- Quase iguais: **А, Е, К, М, О, Т**.
- Falsas amigas: **В (v), Н (n), Р (r), С (s), У (u), Х (rr)**.
- Já dá para ler: **МАМА, КОТ, МЕТРО, ТЕАТР, РЕСТОРАН, САХАР**.
