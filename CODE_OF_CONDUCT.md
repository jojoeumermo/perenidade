# Código de conduta

O Instituto Lúcia é feito por voluntários para que qualquer pessoa estude de graça. Este código vale para o repositório, as issues, as revisões de código e todos os espaços de trabalho do projeto.

## O que esperamos

- Respeito. Divergência de ideias é bem-vinda; ataque a pessoas, não.
- Paciência com quem está começando. Todo mundo começou um dia.
- Crítica ao código, nunca a quem o escreveu.
- Cuidado com dados pessoais: não exponha ninguém, nem em exemplo.

## O que não aceitamos

Racismo, machismo, LGBTfobia, capacitismo, xenofobia, intolerância religiosa, apologia ao nazismo e ao fascismo, assédio, ameaça, exposição de dados de terceiros e qualquer coisa que a lei brasileira proíba.

## O que acontece

Quem quebrar estas regras pode ter a mensagem apagada, ser advertido ou sair do projeto, por decisão da coordenação. Para relatar um caso, escreva para **institutolucia@tutamail.com** (o relato é tratado com sigilo).

Baseado no espírito do Contributor Covenant, adaptado às regras de convivência do site ([Termos de uso](https://institutolucia.org/pt/termos)).
